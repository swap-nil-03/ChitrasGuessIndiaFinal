# ChitraGuess India v4

- Final-game result dialog with winner, final leaderboard, host-only Play Again and Exit for all players.
- Result dialog uses mobile viewport sizing and sticky action buttons.
- Points awarded to every player with an accepted correct guess (once per round); drawer receives a teamwork bonus.
- Portrait mobile chat moved above the board; newest messages are rendered first and auto-anchored to the top.
- Everyday Objects category includes household rooms/items, street, transport and nature prompts.
- Added Hindi and Marathi Devanagari answer aliases for common objects and many Indian movie/song/culture/city/festival/cricket prompts.

## Validation
Source changes and package structure were reviewed. A complete dependency installation and production build were not run in this environment. Run `npm.cmd install` and `npm.cmd run build` on the Windows development machine before deploying.
